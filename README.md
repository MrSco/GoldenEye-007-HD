# GoldenEye 007 HD

GoldenEye 007 HD texture pack for GLideN64, created by **intermissionfb**. Font textures made by **GhostlyDark**, as well as HD textures for `GoldenEye with Mario Characters` ported from SM64 Reloaded.

![](/ge007-hd.jpg)


## This fork: GoldenEye VR's AI fill

This is [GoldenEye VR](https://github.com/MrSco/goldeneye-vr)'s fork. It adds
`GOLDENEYE/AI/`, AI upscales of the game's own textures for the ones this
pack doesn't cover yet (guards, weapons, parts of levels). All of the pack
above is intermissionfb's and GhostlyDark's work. The AI textures only fill
gaps and never replace theirs.

- **How they were made:** GoldenEye VR's `tools/texai`.
  - The gaps are found with this repo's `ge007.tdb`.
  - Each texture is named from the ROM the way GLideN64 does, then upscaled
    with SeedVR2 on a local GPU.
  - Colours and cut-out edges are locked back to the original.
- **Download:** the GoldenEye VR launcher's Mods page offers
  "GoldenEye 007 HD + AI". It's this fork's release zip: the pack at the
  sizes of its HD release, plus `GOLDENEYE/AI/`. It's plain GLideN64 PNGs,
  so it works in emulators too.
